# ❤️ Heart Disease Prediction

A machine learning project that predicts whether a patient is likely to have heart disease from clinical measurements. It includes exploratory data analysis, data cleaning, a comparison of five classifiers, saved model files (`.pkl`), and a **Streamlit web app** for making predictions through a simple GUI.

> ⚠️ **Disclaimer:** This project is for educational purposes only. It is not a medical device and must not be used for real diagnosis or treatment decisions.

## 📊 Dataset

The notebook reads `heart.csv` (Heart Failure Prediction dataset, 918 patients, no missing values or duplicates).

| Feature | Description |
|---|---|
| `Age` | Age of the patient (years) |
| `Sex` | `M` / `F` |
| `ChestPainType` | `ASY` (asymptomatic), `ATA` (atypical angina), `NAP` (non-anginal pain), `TA` (typical angina) |
| `RestingBP` | Resting blood pressure (mm Hg) |
| `Cholesterol` | Serum cholesterol (mg/dl) |
| `FastingBS` | Fasting blood sugar > 120 mg/dl (`1` = yes, `0` = no) |
| `RestingECG` | `Normal`, `ST`, `LVH` |
| `MaxHR` | Maximum heart rate achieved |
| `ExerciseAngina` | Exercise-induced angina (`Y` / `N`) |
| `Oldpeak` | ST depression induced by exercise |
| `ST_Slope` | Slope of the peak exercise ST segment: `Up`, `Flat`, `Down` |
| `HeartDisease` | **Target**: `1` = heart disease, `0` = normal |

---

## 🔬 Workflow

1. **EDA:** shape, info, describe, duplicates, nulls, class balance, histograms with KDE, count plots, box/violin plots and a correlation heatmap.
2. **Data cleaning:** `Cholesterol` had 172 zero values and `RestingBP` had 1, which are physiologically impossible. Zeros were replaced with the mean of the non-zero values (≈ 244.64 and ≈ 132.54).
3. **Encoding:** categorical columns one-hot encoded with `pd.get_dummies(drop_first=True)`.
4. **Split & scale:** 80/20 train-test split (`random_state=42`) and `StandardScaler` fit on the training set only.
5. **Modelling:** five classifiers trained and compared on accuracy and F1.
6. **Export:** the best model, the scaler and the feature list are saved with `joblib`.

### Results (test set)

| Model | Accuracy | F1 Score |
|---|---|---|
| **Logistic Regression** | **0.8696** | **0.8846** |
| KNN | 0.8641 | 0.8815 |
| Naive Bayes | 0.8478 | 0.8614 |
| SVM | 0.8478 | 0.8667 |
| Decision Tree | 0.7772 | 0.7980 |

Logistic Regression performed best and is the model saved for the app.

## 📦 Pickle Files

| File | Contents | Created by |
|---|---|---|
| `heart_disease_model.pkl` | Trained `LogisticRegression` | `joblib.dump(models['LogisticRegression'], ...)` |
| `scaler.pkl` | Fitted `StandardScaler` | `joblib.dump(scaler, ...)` |
| `features.pkl` | List of the 15 feature names, in training order | `joblib.dump(x.columns.tolist(), ...)` |

Feature order used by the model:

```
Age, RestingBP, Cholesterol, FastingBS, MaxHR, Oldpeak, Sex_M,
ChestPainType_ATA, ChestPainType_NAP, ChestPainType_TA,
RestingECG_Normal, RestingECG_ST, ExerciseAngina_Y,
ST_Slope_Flat, ST_Slope_Up
```

### Using the model in your own code

```python
import joblib
import pandas as pd

model = joblib.load("heart_disease_model.pkl")
scaler = joblib.load("scaler.pkl")
features = joblib.load("features.pkl")

patient = pd.DataFrame([{
    "Age": 54, "RestingBP": 140, "Cholesterol": 239, "FastingBS": 0,
    "MaxHR": 160, "Oldpeak": 1, "Sex_M": 1,
    "ChestPainType_ATA": 0, "ChestPainType_NAP": 1, "ChestPainType_TA": 0,
    "RestingECG_Normal": 1, "RestingECG_ST": 0, "ExerciseAngina_Y": 0,
    "ST_Slope_Flat": 0, "ST_Slope_Up": 1,
}]).reindex(columns=features, fill_value=0)

X = scaler.transform(patient)
print("Prediction:", model.predict(X)[0])          # 1 = heart disease
print("Probability:", model.predict_proba(X)[0][1])
```

## 🖥️ Streamlit GUI

`app.py` loads the three pickle files and gives you a form to enter patient details. It applies the same encoding and scaling as the notebook, then shows the predicted risk and its probability.

### Run it

```bash
streamlit run app.py
```

Then open <http://localhost:8501> in your browser.

The `.pkl` files must be in the same folder as `app.py`.

### What the app does

- Collects all 11 clinical inputs (age, sex, chest pain type, blood pressure, cholesterol, etc.)
- One-hot encodes them to match the training columns
- Aligns the columns to `features.pkl` and scales them with `scaler.pkl`
- Displays a **High risk / Low risk** result with the model's probability

## ⚠️ Notes & Limitations

- **Oldpeak is truncated to an integer.** The notebook calls `.astype(int)` on the encoded data, so the model was trained with whole-number `Oldpeak` values. The Streamlit app applies the same truncation to stay consistent. Removing that cast in the notebook and retraining would preserve the decimals.
- Mean imputation for zero `Cholesterol` values is simple; more robust approaches (median, model-based imputation) may improve results.
- Metrics come from a single train/test split; cross-validation and hyperparameter tuning would give a more reliable estimate.
- The dataset is small (918 rows), so results may not generalise to other populations.
